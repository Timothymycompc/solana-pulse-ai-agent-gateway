Live Solana data, ready to use

You send a request to a web address. The gateway does the Solana work and sends back a clean, structured answer. This page covers which call to pick, what it costs, and how to get started.

New to APIs? Start with What is a call?

Free reads, then pay per call

Basic reads are free (rate-limited). Every other tool has 3 free calls, shared between HTTP and MCP, then costs $0.001 to $0.01 in USDC per successful call. You pay with each request through the open x402 protocol: no account, no API key, no prepaid balance.

Free and free calls TRY

Basic reads are always free. Each paid tool can be tried 3 times.

  1. You send a requestNo sign-in and no key.
  2. The gateway checks and prepares itFills in supported defaults and validates inputs.
  3. Live data is fetched from SolanaRead live from the chain, not from a stale copy.
  4. You get a clean answerStructured JSON.

Paid calls $0.001–$0.01 USDC

Once a paid tool's 3 free calls are used.

  1. The gateway asks for paymentHTTP 402 with a PAYMENT-REQUIRED header naming the exact USDC amount.
  2. Your client pays and retriesAn x402 client signs the USDC transfer and resends the call with a PAYMENT-SIGNATURE header.
  3. The tool runsThe transfer settles on Solana only if the call succeeds; network fees are covered.
  4. You get the answer and a receiptThe PAYMENT-RESPONSE header holds the transaction signature.

Which call should I use?

Start from the question you want answered. Every call also accepts an optional network (default mainnet-beta). Where an input is left blank, the gateway picks a sensible live value for most calls and reports what it chose.

About the pre-flight check. It tells you what it checked, for example whether the fee payer can cover the base fee, and shows the result of a dry run. It is a check for common mistakes, not a guarantee that a transaction will succeed.

About token authority risk. The token profile reports mint and freeze authorities. Its freeze-authority risk flag is a heuristic and does not detect honeypots or guarantee whether a token is safe to trade.

Pay per call with x402

There is no signup, no email and no API key. Paid calls are paid one at a time in USDC on Solana with the x402 protocol, so any agent or app with a Solana wallet can pay automatically.

Step 1

Get a Solana wallet with USDC

A few cents of USDC covers many calls. You do not need SOL for fees; the payment facilitator covers network fees.

Step 2

Use an x402 client

Wrap your HTTP client with @x402/fetch, or your MCP client with @x402/mcp. It answers the 402 by signing the exact USDC transfer.

Step 3

Call as usual

Paid calls settle only when they succeed. Each response carries a PAYMENT-RESPONSE receipt with the Solana transaction signature.

curl -i "https://YOUR-GATEWAY/api/solana/token-profile?mint=<token_mint>"
# After 3 free calls: HTTP/1.1 402 Payment Required + PAYMENT-REQUIRED header
