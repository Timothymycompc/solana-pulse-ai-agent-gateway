Live Solana data, ready to use

You send a request to a web address. The gateway does the Solana work and sends back a clean, structured answer. This page covers which call to pick, what it costs, and how to get started.

New to APIs? Start with What is a call?

Try calls, then pay per call

Each visitor gets 3 free calls to every tool, shared between HTTP and MCP. No wallet sign-in is needed to try the service. After a tool's 3 free calls, each successful call to it costs 0.0022 SOL (one credit); sign in with a wallet to add credits.

Which call should I use?

Start from the question you want answered. Every call also accepts an optional network (default mainnet-beta). Where an input is left blank, the gateway picks a sensible live value for most calls and reports what it chose.

About the pre-flight check. It tells you what it checked, for example whether the fee payer can cover the base fee, and shows the result of a dry run. It is a check for common mistakes, not a guarantee that a transaction will succeed.

About token authority risk. The token profile reports mint and freeze authorities. Its freeze-authority risk flag is a heuristic and does not detect honeypots or guarantee whether a token is safe to trade.

Get a key and add credits

You can try each data call 3 times without signing in. After that, sign in with a Solana wallet to add credits. There is no signup form and no email.

Step 1

Sign in with your wallet

Request a short message, sign it with your wallet, and send the signature back. Signing in is free and sends nothing to the network. You get an API key.

Step 2

Add credits

Send SOL from the same wallet to the gateway address. Credits are added automatically when the deposit is detected, at 0.0022 SOL per paid call.

Step 3

Make a call

Send your key in the x-api-key header. Responses show your remaining credits in the x-credits-remaining header.

curl "https://YOUR-GATEWAY/api/solana/token-profile?mint=<token_mint>" \
  -H "x-api-key: <your_key>"

Keys cannot be recovered, because only a hash is stored. Signing in again issues a new key and retires the old one. The exact commands and the deposit address are on the Pricing and Top-Up tab.
