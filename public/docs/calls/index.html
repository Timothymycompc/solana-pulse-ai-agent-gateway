New to APIs?

What is a call?

A call is one question you send to the gateway and the one answer you get back. Ask "how much SOL is in this wallet?" and you get the number. That round trip is one call.

What one looks like

Each kind of question has its own web address, called an endpoint or tool. You add your details to the address, and the answer comes back as structured data (JSON) that a program or AI agent can read.

The question

POST https://YOUR-GATEWAY/api/tools/get_solana_balance
{ "wallet": "<wallet_address>" }

The answer

{
  "wallet": "<wallet_address>",
  "network": "mainnet-beta",
  "lamports": "1500000000",
  "sol": "1.5",
  "slot": 455508107
}

AI agents make the same calls through MCP. Instead of a web address, the agent picks a tool by name, such as get_solana_balance, and gets the same answer.

What calls cost

Every paid tool can be called 3 times free, with no wallet and no sign-up. The count is kept per tool, so trying one tool does not use up the free calls of another. A website call and its matching MCP tool share the same 3.

Basic tools, like this balance call, are always free. For paid tools, after the 3 free calls each successful call costs $0.001 to $0.01 in USDC, paid with the request itself through x402. Calls that end in an error are never charged and do not use up a free call.
